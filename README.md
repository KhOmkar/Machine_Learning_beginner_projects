# Machine_Learning_beginner_projects

A collection of beginner-friendly machine learning projects to help you get started with ML concepts.

## Projects

### 1. Simple Linear Regression (`linear_regression.py`)

A simple Python program that demonstrates how to train a linear regression model using scikit-learn.

**Features:**
- Generates sample data for demonstration
- Splits data into training and testing sets
- Trains a linear regression model
- Evaluates the model using Mean Squared Error and R² score
- Visualizes the regression line with training and test data

**How to run:**
```bash
# Install dependencies
pip install -r requirements.txt

# Run the program
python linear_regression.py
```

The program will output:
- Model parameters (coefficient and intercept)
- Evaluation metrics (MSE and R² score)
- A visualization saved as `linear_regression_plot.png`
